---
title: "Origins"
---
Every player picks three origins, one from each layer, and has the powers of all three.

| Order | Layer | Notes |
|---|---|---|
| 1 | [Ancestry](ancestries.md) | Each has a [race item](race-items.md) |
| 2 | [Class](classes.md) | Any class goes with any ancestry |
| 3 | [Size](sizes.md) | Defaults to Normal Size |

## Reading an origin

| Entry | Meaning |
|---|---|
| Impact | Origins-Reborn's rating of how much the origin changes the game, None to High |
| Icon | The item that stands for it |
| File | Its file in `plugins/ArdanBorn/origins/` |
| From | The plugin a power comes from |

## Powers

Details are on the [Powers](powers.md) page. An addon's powers do nothing if the addon isn't installed; see [Optional addons](installation.md#optional-addons).

To keep an origin from being picked, see [Hiding origins](installation.md#hiding-origins).
